## Overages

All plans include hard monthly caps. When a cap is reached:
- **Messages**: Bot pauses outgoing replies until next billing cycle
- **AI Requests**: Falls back to quick replies and knowledge base only
- **Broadcasts**: Cannot create new campaigns until reset

Caps reset automatically on the 1st of each calendar month.

## Feature Flags

Plans control feature access through flags:
- `broadcasts`: Enable broadcast campaigns
- `knowledge_base`: Knowledge base import and matching
- `follow_ups`: Automated customer follow-up nudges
- `templates`: Custom message templates
- `daily_report`: Daily AI business summary
- `api_access`: External API integration
- `custom_persona`: Custom bot personality

## Billing

- Monthly billing: 30-day cycle
- Yearly billing: 365-day cycle
- Payment via bank transfer / InstaPay / Vodafone Cash
- No auto-renewal — admin manually renews
- Cancellation: Admin cancels subscription, access revoked at expiry
