## ملاحظات مهمة للعميل
- **الدفع:** يتم اختيار الباقة وطريقة الدفع من لوحة التحكم، ترفع إيصال التحويل، ويعتمده فريق المالية فيُفعّل اشتراكك ويُشحن رصيدك تلقائيًا (عادةً خلال ٢٤ ساعة).
- **محفظة Meta:** عند استخدام واتساب Cloud API الرسمي، تُحسب تكلفة محادثات Meta من رصيد المحفظة المسبق الدفع (منفصل عن سعر الاشتراك) وفق أسعار Meta لكل دولة/فئة.
- **«0 = غير محدود»** في الحدود يعني بلا سقف في باقة Enterprise.
- **«قريبًا»** = ميزة قيد الإطلاق وستتوفّر لمشتركي الباقة عند إطلاقها دون تكلفة إضافية.
- الترقية فورية، والاشتراك السنوي يوفّر قيمة شهرين.

## أهم ٣٠ ميزة وفايدتها (كل ميزة = حلّ لمشكلة حقيقية)

| # | الميزة | الفايدة لأعمالك |
|---|---|---|
| 1 | صندوق وارد واتساب موحّد | كل محادثات عملائك في شاشة واحدة — لا رسالة تضيع أو تتكرّر. |
| 2 | ردود تلقائية ذكية ٢٤/٧ | رد خلال ثوانٍ في أي وقت — العميل لا ينتظر ولا يذهب لمنافس. |
| 3 | المساعد الذكي + قاعدة المعرفة | البوت يتعلّم منتجاتك وأسعارك وسياساتك فيرد بدقة بدل ردود عامة. |
| 4 | رصد الطلبات تلقائيًا | يكتشف نية الشراء ويسجّل الطلب من المحادثة ويبلّغك فورًا — لا طلب يفوت. |
| 5 | إدارة العملاء (CRM) | ملف لكل عميل بسجل محادثاته وطلباته — تعرف عميلك وتتابعه. |
| 6 | تقييم العملاء المحتملين | يرتّب الأقرب للشراء فتركّز جهد فريقك على الصفقات الجاهزة. |
| 7 | خطّ أنابيب المبيعات | تابع كل صفقة من أول رسالة حتى الإغلاق — لا فرصة تُنسى. |
| 8 | تقسيم العملاء لشرائح | استهدف كل فئة (جدد/متكرّرين/متعثّرين) برسالة مناسبة لها. |
| 9 | حملات البثّ الجماعي | وصّل عرضك لآلاف العملاء برسالة واحدة + قِس التفاعل. |
| 10 | منشئ الحملات الذكي | يساعدك تكتب الرسالة المناسبة وتجدولها في التوقيت الأفضل. |
| 11 | المتابعة الذكية واستعادة العملاء | يتابع تلقائيًا من لم يكمل طلبه (سلة متروكة) → مبيعات مستردّة. |
| 12 | أتمتة سير العمل (بدون كود) | قواعد if-this-then-that: تنبيه عند الشحن، تذكير لمن لم يرد، تصنيف تلقائي. |
| 13 | ساعات العمل وردود خارج الدوام | العميل يجد دائمًا ردًّا لائقًا حتى بعد إغلاق المتجر. |
| 14 | الردود السريعة الجاهزة | رُدّ على الأسئلة المتكرّرة بضغطة واحدة ووفّر وقت فريقك. |
| 15 | تحليلات متقدّمة + إسناد الإيرادات | تعرف أي قناة/حملة تجلب المال فعليًا فتضاعف ما ينجح. |
| 16 | تقارير تنفيذية وتوقّع الإيرادات | قرارات مبنية على أرقام حقيقية لا على تخمين. |
| 17 | واتساب Cloud API الرسمي (Meta) | استقرار وموثوقية أعلى + قوالب معتمدة + حدود إرسال أكبر. |
| 18 | أرقام واتساب متعدّدة | افصل الفروع أو الأقسام على أرقام مختلفة من لوحة واحدة. |
| 19 | فريق عمل بصلاحيات + متعدّد الفرق | وزّع العمل بأمان — كل عضو يرى ما يخصّه فقط. |
| 20 | الولاء والمكافآت | حافظ على عملائك الحاليين وأعِد تنشيطهم — أرخص من اكتساب جديد. |
| 21 | تكاملات المتاجر + API | اربط Shopify / WooCommerce / Salla / Zid وأنظمتك لمزامنة الطلبات. |
| 22 | محفظة مسبقة الدفع + فوترة Meta شفّافة | تحكّم كامل في تكلفة المحادثات وتشاهد كل عملية خصم. |
| 23 | مركز صحة الأنظمة | حالة واتساب/Meta/الذكاء في لحظة، مع إصلاح بضغطة (اختبار/إعادة ربط/تبديل). |
| 24 | بديل مزوّد الذكاء التلقائي (Failover) | لو توقّف مزوّد، يعمل البديل تلقائيًا — الردود لا تتوقّف. |
| 25 | أمان وحماية وسجل تدقيق | تشفير + نسخ احتياطي + تسجيل كل إجراء مالي/حسّاس (من فعل ماذا ومتى). |
| 26 | يفهم الصوت والصورة والنص | العميل يراسلك بأي شكل والبوت يفهمه ويرد. |
| 27 | رؤى متقدّمة عن العملاء | يكشف سلوك الشراء والاهتمامات لتخصيص العروض. |
| 28 | مسارات الموافقات + Flow Builder *(قريبًا)* | اعتماد قبل الإجراءات الحسّاسة + تصميم رحلات أتمتة معقّدة بصريًا. |
| 29 | إدارة الفروع المتعدّدة *(قريبًا)* | كل فرع ببياناته وتقاريره المستقلّة. |
| 30 | علامة بيضاء + بنية مخصّصة + SLA | قدّم المنصة باسمك (للوكالات) أو بنية وخدمة مخصّصة للمؤسسات. |

## بندعم إيه؟
- **القناة:** واتساب — ربط سريع بكود QR، أو واتساب Cloud API الرسمي من Meta.
- **التكاملات:** Shopify · WooCommerce · Salla · Zid · API للمطوّرين · Webhooks مخصّصة.
- **طرق دفع الاشتراك:** فودافون كاش · إنستاباي · تحويل بنكي · Binance · USDT · PayPal · RedotPay · Bybit · Kast · (+ بوابات Paymob / Stripe).
- **اللغة والوسائط:** عربي وإنجليزي بواجهة RTL كاملة · يفهم النص والصوت والصور.

## ليه KEYONE؟ (مميزاتنا)
- ⭐ كل شيء داخل واتساب — حيث عملاؤك فعلًا، بلا تطبيق جديد.
- ⭐ ذكاء اصطناعي يتعلّم من بياناتك — ردود دقيقة لا قوالب جامدة.
- ⭐ يعمل بدون مطوّر — دفع وباقات وفِرق وحوادث وصحة الأنظمة من اللوحة.
- ⭐ شفافية مالية كاملة — محفظة مسبقة + سجل تدقيق لكل عملية.
- ⭐ موثوقية عالية — بديل مزوّد ذكاء تلقائي ومراقبة صحّة مستمرة.
- ⭐ عربي أولًا — تجربة RTL احترافية مصمّمة لسوقك.

## بنحلّ مشاكل إيه؟
- → رسائل عملاء تضيع وردّ متأخر → رد فوري ٢٤/٧.
- → ساعات مهدورة على الردود اليدوية → أتمتة كاملة.
- → طلبات تفوت بين الرسائل → رصد تلقائي وتنبيه فوري.
- → عملاء يتركون السلة → متابعة تلقائية تستردّهم.
- → لا رؤية للأداء → تحليلات وتقارير تنفيذية.
- → فوضى إدارة الفريق → أدوار وصلاحيات واضحة.
- → تعقيد تقني → إعداد في دقائق بدون كود.
